# 社会经济系统区域联合研究中心网站

这是联合研究中心网站的本地第一版，当前采用静态页面实现，便于审阅视觉、栏目和中英文内容。新闻、通知、项目和成果均预留了后续接入内容管理后台的位置。

## 本地预览

在 `site` 目录运行：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。

## 当前功能

- 中英文切换并记住访问者选择；
- 电脑端和手机端响应式导航；
- 首页完整内容结构；
- 新闻与通知筛选；
- 研究领域、合作项目、成果、组织机构和成员单位展示；
- 无外部字体和脚本依赖，便于国内外访问；
- 本地 SVG 站点图标和本地主视觉图片。
